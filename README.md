# VerityTrade

> Trade like it's real — without the risk.

VerityTrade is a realistic, browser-based trading simulator built to feel like a
genuine trading terminal — not a toy. It combines a premium, minimal interface
with mechanics modeled on real markets: limit/stop orders, leverage and margin,
long/short positions, live order book depth, and full portfolio analytics.

## Features

- **Live-style candlestick charts** with multiple timeframes and indicators
- **Real order types** — Market, Limit, Stop, Stop-Limit, with TP/SL
- **Leverage & margin** trading, long and short positions
- **Order book & time & sales** simulation for realistic market depth
- **Portfolio analytics** — equity curve, drawdown, win rate, Sharpe ratio
- **Watchlist & price alerts**
- **Persistent state** — your portfolio survives a refresh
- Clean, light, luxury-inspired interface

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Lightweight Charts](https://github.com/tradingview/lightweight-charts) for market visualization

## Getting Started

```bash
git clone https://github.com/<your-username>/verity-trade.git
cd verity-trade
# open index.html in your browser, or serve locally:
npx serve .
```

## Disclaimer

VerityTrade is a **simulation only**. No real funds, no real markets, no financial
advice. All prices and market data are generated for educational and entertainment
purposes.
